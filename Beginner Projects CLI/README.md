# Beginner Projects CLI

Two standalone, command-line friendly OpenCV examples: **thresholding** and **contour analysis**. Each can read the included test images, write result images to `outputs/`, and optionally open a display window. The scripts do not import one another.

## Install and run (Windows PowerShell)

```powershell
python -m pip install -r requirements.txt
python threshold.py
python contours.py
```

Optional interactive display:

```powershell
python threshold.py --mode otsu --show
python contours.py --min-area 600 --show
```

Try another image:

```powershell
python threshold.py --image "C:\path\to\your_image.jpg" --mode binary --threshold 120 --show
python contours.py --image "C:\path\to\your_image.jpg" --min-area 1200 --show
```

## Included assets and output

- `test_images/geometric_scene.png` — synthetic geometric test image.
- `test_images/threshold_scene.png` — grayscale input for threshold examples.
- `outputs/threshold_output.png` — generated by the threshold script.
- `outputs/contours_output.png` and `outputs/contours_output_mask.png` — generated by the contour script.

**Interpretation:** contours are only as meaningful as the binary mask; background texture, illumination and the selected minimum area affect results.
